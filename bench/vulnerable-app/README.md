# Übungsprojekt (absichtlich unsicher)

Dieses kleine Projekt enthält **mit Absicht** typische Sicherheitslücken. Vigil nutzt es
für den Beispiel-Lauf beim ersten Start und um zu messen, wie gut jedes KI-Modell findet
(`npm run bench`). Nicht ausführen, nicht deployen. Alle Schlüssel sind erfunden.
