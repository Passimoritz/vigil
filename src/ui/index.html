    Analyse
    
          
    
            
    GründlichkeitGründlich = fünf fokussierte Durchgänge (Zugriff, Injection, Krypto, Logik, Konfig). Findet mehr, kostet mehr.
    
            
          
    
          
    
            
    KostenbremseVor dem Start nachfragen, wenn ein Cloud-Lauf voraussichtlich mehr kostet.
    
            
          
    
          
    
            
    Genauigkeit der KI
    
            
    0.1
    
          
    
          
    
            
    Schwachstellen-DatenbankAbhängigkeiten (npm, PyPI, Maven, Go, Cargo, RubyGems) gegen OSV.dev prüfen. Kostenlos, braucht Internet.
    
            
          
    
        
    

        
    
          
    Belastbarkeit & Datenschutz
    
          
    
            
    KI-Befunde gegenprüfenEin zweiter KI-Schritt versucht jeden reinen KI-Fund am Code-Ausschnitt zu widerlegen. Widerlegtes fliegt raus.
    
            
          
    
          
    
            
    Secrets schwärzenBevor Code an externe KI-Anbieter geht. Lokale Modelle sehen den Code unverändert, dort verlässt nichts den Rechner.
    
            
          
    
        
    

        
    
          
    Freigegebene Ziele
    
          
    Webadressen und Server prüft Vigil nur, wenn sie hier stehen oder du sie beim Hinzufügen bestätigst. example.com gilt auch für Subdomains, *.example.com nur für Subdomains. Die REST-API darf nur Ziele von dieser Liste prüfen.
    
          
        
    

        
    
          
    Tiefe Prüfungen & Threat-Intel
    
          
    
            
    Browser-LaufzeitprüfungFür verifizierte Webseiten: Tokens im Speicher, Drittskripte ohne SRI, unverschlüsselte Aufrufe.
    
            
          
    
          
    
            
    Threat-Intel (CISA KEV, EPSS)
    
            
          
    
        
    

        
    
          
    API-Rechtematrix (BOLA/IDOR)
    
          
    Vigil holt mit dem Token von Nutzer A dessen Objekt und versucht denselben GET-Aufruf ohne Anmeldung und mit dem Token von Nutzer B. Nur GET, nur verifizierte Domains, nur mit Test-Konten deiner eigenen Anwendung.
    
          
    
            
            
            
            
            
          
    
          
    
        
    

        
    
          
    Externe Sicherheits-Tools
    
          
    
            
    Installierte Tools einbeziehengitleaks, trufflehog, trivy, grype, semgrep, bandit, checkov, retire.js, hadolint, osv-scanner. Bei freigegebenen Servern zusätzlich nmap und nuclei, ohne DoS und ohne Brute-Force. Fehlende Tools werden übersprungen.
    
            
          
    
        
    

        
    
          
    Eigene Regeln & Muster
    
          
    Eigene Muster als regulären Ausdruck, z. B. ein firmeninternes Schlüsselformat.
    
          
    
          
          
    
            Eingebaute Regeln deaktivieren
            
    
          
    
        
    

        
    
          
    Netzwerk: Proxy / VPN
    
          
    Leer = Direktverbindung. Unterstützt http://, https://, socks5:// (z. B. Tor unter socks5://127.0.0.1:9050) und socks4://.
    
          
    
            
            
          
    
          
    
        
    

        
    
          
    Server-Adressen der KI-Anbieter
    
          
    Nur für eigene Server (z. B. Ollama auf einem anderen Rechner) oder OpenAI-kompatible Dienste. Leer = Standard.
    
          
    
        
    

        
    
          
    Lokale REST-API
    
          
    
            
    REST-API anbietenFür Skripte und CI auf diesem Rechner. Lauscht nur auf 127.0.0.1, verlangt das Token und prüft nur freigegebene Ziele.
